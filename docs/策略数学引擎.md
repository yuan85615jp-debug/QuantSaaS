# 策略数学引擎

**文档目标:** 定义 Step() 函数的完整输入输出契约，以及内部各层（市场状态感知、宏观引擎、微观引擎、仓位三态）的计算逻辑。本文件是策略实现的唯一数学规格书。

---

## 第 0 章：引擎身份

`Step()` 是纯函数无状态转换器。

- 唯一外部入口：`Step(StrategyInput) → StrategyOutput`
- 回测路径与实盘路径必须调用同一个实现，内部禁止 `if isBacktest` 分支
- 策略代码内部绝对禁止：定时器、网络请求、数据库读写、任何文件 I/O
- 所有决策只依赖传入的 `StrategyInput` 快照

---

## 第 1 章：资产结构三态（Portfolio State）

| 状态 | 语义 | 可操作 |
|------|------|--------|
| **DeadHold**（DeadStack） | 宏观长期底仓 | 只进不出（释放规则见第 6 章） |
| **FloatHold**（FloatStack） | 微观浮动仓 | 可买可卖 |
| **ColdSealedHold**（ColdSealedStack） | 冷封存 | 永不释放 |

### 通用公式

```
TotalEquity     = Cash + DeadHold×Price + FloatHold×Price + ColdSealedHold×Price
ReserveFloor    = TotalEquity × micro_reserve_pct
SpendableCNY    = max(0, Cash - ReserveFloor)
CurrentMicroWeight = FloatHold × Price / TotalEquity   （若 TotalEquity=0 则为 0）
```

- `micro_reserve_pct` / `MicroReserveRate`：可进化参数，语义为保留现金比例或每次微观调拨比例。

## 第 4 章：宏观引擎（“老农定投模型”）

宏观引擎关注长期趋势，决定何时向 DeadHold 注入资金（类 DCA）。

### 可进化宏观基因（进入 LunarGenome）

| 基因 | 语义 |
|------|------|
| MaxDCAMonths | 最大定投月数，防止阴跌中过早打光储备 |
| BetaThreshold | 大盘偏离度阈值，触发滴灌或深跌加仓 |
| MoonPhasePressure | 月相压力，接近满月时放大定投强度 |
| DeadlineForcePct | 耐心耗尽时的强制动用比例 |
| GCThresholdMonths / GCMaxRatio | 长期闲置回收门槛与上限 |
| TMacro / TMicro / TDeadline / EMAAnchor | Timing 结构基因 |

宏观买入形成的份额进入 **DeadHold**，仅按第 6 章规则可解封。

## 第 5 章：微观引擎 — Sigmoid + PDE 狙击手

### 5.1 Sigmoid 动态天平（目标权重）

```
CurrentWeight  = FloatHold × Price / TotalEquity

Signal         = 【归一化市场信号，正值倾向减仓，负值倾向加仓】
               # 可由 PDE 合成：Signal ≈ kp·位置项 + kv·速度项 + ka·加速度项 + ...

EffectiveBeta  = max(0.01, β × MarketBetaMultiplier)
InventoryBias  = clamp(CurrentWeight, 0, 1) − 0.5
Exponent       = EffectiveBeta × Signal + γ × InventoryBias

TargetWeight   = 1 / (1 + exp(Exponent))   # clamp 到 [0, 1]
```

### 5.2 PDE 动力学权重（微观基因组）

| 基因 | 语义 |
|------|------|
| kp | 位置权重：当前价格距离均值的引力系数 |
| kv | 速度权重：对一阶导数（价格变化率）的敏感度 |
| ka | 加速度权重：对二阶导数的敏感度，决定高位逃顶锐度 |
| MinTradeThreshold | **关键**：|TargetWeight − CurrentWeight| 达到此阈值才允许开火，过滤震荡市无效交易 |
| MicroReserveRate | 每次开火动用可用资金的百分比 |

### 5.3 理论订单与粉尘/摩擦过滤

```
DeltaWeight    = TargetWeight − CurrentWeight
TheoreticalCNY = DeltaWeight × TotalEquity
```

- `|TheoreticalCNY| ≥ MinTradeThreshold 对应金额` 且满足 LotStep / LotMin：生成订单
- 否则：粉尘拦截或单位截断，不下单（回测中计入适应度惩罚）

## 第 6 章：DeadHold 释放规则（库存桥）

宏观定投买入的 DeadHold **必须等待**微观引擎侦测到加速度（ka 相关信号）飙升或满足其它明确解封条件时，才可转为 FloatHold。

- 仅改变 SaaS 侧账本语义（DeadStack → FloatStack），**不下发 TradeCommand**
- 回测必须精准记录这一转移，与实盘同构

（具体数值阈值由策略作者与可进化参数共同定义）

---

## 第 7 章：可进化参数契约（Chromosome / LunarGenome）

宏观基因 + 微观基因 + Sigmoid 参数一体进入染色体，由 GA 交叉与变异。

| 参数 | 类型 | 语义 | 是否染色体 | 备注 |
|------|------|------|------------|------|
| MaxDCAMonths 等宏观基因 | int/float | 见第 4 章 | 是 | 进入 LunarGenome |
| kp, kv, ka | float64 | PDE 动力学 | 是 | |
| MinTradeThreshold | float64 | 开火偏差阈值 | 是 | 极关键 |
| MicroReserveRate / micro_reserve_pct | float64 | 调拨/保留比例 | 是 | |
| β, γ, SigmoidScale | float64 | Sigmoid 激进与偏置 | 是 | |
| … | … | 策略特有因子 | 是 | |

**出生点 / Environment 参数（Epoch 级冻结，不进入基因组）**：CapitalPolicy、RiskBounds、DeadReserveRatio、GlobalStopLoss、MaxLeverage 等。

**Season 层参数**：Aggressiveness Multiplier 等，Epoch 内固定，跨 Epoch 重采样，进化后转为 Runtime Arguments。

硬边界与结构约束由策略的 `Clamp` / `Validate` 实现。
