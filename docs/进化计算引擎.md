# 进化计算引擎

**文档目标:** 将进化系统降维为一个纯粹的寻优黑盒。进化引擎不关心具体策略内部结构，只通过抽象接口驱动种群生命周期。具体策略的染色体字段、边界、适应度语义由策略模块定义。

**核心准则（物理意义）:**  
GA 的目的**绝不是**寻找历史最高收益率（那只是过拟合的数字游戏），而是要在约 10 年、覆盖 A 股 ETF / 黄金 ETF 等现货标的的极端市场环境（暴涨、阴跌、极端回撤与流动性冲击）中，寻找一个能够完美平衡 **“高胜率决策”** 与 **“极低摩擦成本”** 的数学极值点。

回测与进化模块是独立于实盘执行端（Live Agent）的实验室。它必须绝对冷酷，以 **“全悲观”** 假设进行压力测试。

---

## 0. 核心定位

进化引擎是一个**纯计算线程**：接收策略提供的基因空间与评估函数，对种群执行多代进化，交付最优基因集（Challenger → 人工 Promote 为 Champion）。

引擎不关心：策略内部的信号公式、仓位三态语义、特定时钟机制，也不 import 任何具体策略实现。引擎只知道：基因是一个可采样、可变异、可交叉、可评分的抽象向量。

**输入：** 策略提供的基因空间（边界、约束）+ 历史 K 线数据集 + 进化配置参数 + Environment / Season 层配置  
**输出：** 挑战者（challenger）基因包 JSON，写入数据库，等待人工 Promote 为冠军

## 1. 三层冻结架构（Environment — Season — Genes）

为防止过拟合与“单一环境幻觉”，每次 Epoch 采用三层结构。前端应提供状态窗口，允许人工调整 Environment / Season 参数后再启动进化；进化完成后同样展示三层参数。

### 1.1 顶层：环境（The Physics Laws / 造物主法则）

- **边界**：Epoch 内全员相同，基因层**不参与改写** Environment；只描述物理阻断与底线红线。
- **跨 Epoch 抽样**：以当前冠军包中的 Environment 为均值锚点，对 `DeadReserveRatio`、`GlobalStopLoss` 在合法区间内做截断正态（σ ≈ 区间宽度 10%）；`MaxLeverage` 在 GA Epoch 中固定为 **1**（现货）。
- **参数（当前实现）**：
  - `DeadReserveRatio`：死守的现货底仓下限（安全垫），策略层不得突破。
  - `GlobalStopLoss`：全局权益回撤熔断（0 表示关闭）。
  - `MaxLeverage`：杠杆上限占位（现货基线 = 1）。

### 1.2 中层：季节（The Cyclical Climate）

- 具有周期性特征、决定宏观节奏，但不需要极高精度的参数。
- **核心参数示例**：资金激进乘数（Aggressiveness Multiplier）——从低到高对应冬 / 春 / 夏 / 秋 四档。Epoch 内固定，跨 Epoch 按分类分布重采样（正常档位赋予更高概率）。
- **运作逻辑**：将全样本回测区间切成 4 段，底层种群必须忍受 4 种不同的季节摩擦。
- **运行时约定**：进化结束后，中层参数转化为实盘 SaaS 的【运行时入参（Runtime Arguments）】。云端 Regime Engine 根据实时大盘水位动态抽取季节档位，下发至实例。
- 实验室回测与 GA 评估的步进 tick 与**基准 5 分钟 K 线**对齐；最终种子输出默认 0 偏移（或 1 分钟 Tick）。

### 1.3 底层：战斗种群基因（The Combat Genes / LunarGenome）

宏观战略 + 微观战术同属一条染色体，一体参与交叉与变异。

#### 宏观基因组（“老农定投模型”）
| 基因 | 语义 |
|------|------|
| MaxDCAMonths | 最大定投月数，限制宏观子弹消耗速度 |
| BetaThreshold | 大盘偏离度阈值，触发滴灌/深跌加仓 |
| MoonPhasePressure | 月相压力，接近满月时放大定投强度 |
| DeadlineForcePct / GCThresholdMonths / GCMaxRatio | 耐心耗尽强制比例、长期闲置回收门槛与上限 |
| TMacro / TMicro / TDeadline / EMAAnchor | Timing 结构基因（统计窗口与节奏） |

#### 微观基因组（“狙击手动量模型”）
| 基因 | 语义 |
|------|------|
| kp | 位置权重：价格距离均值的引力系数 |
| kv | 速度权重：一阶导数（价格变化率）敏感度 |
| ka | 加速度权重：二阶导数敏感度，决定高位逃顶锐度 |
| MinTradeThreshold | **关键基因**：目标权重与实际权重偏差达到此阈值才允许开火，过滤震荡市无效交易 |
| MicroReserveRate | 微观每次调拨率：每次开火动用可用资金的百分比 |
| β / γ / SigmoidScale 等 | Sigmoid 动态天平相关参数（与策略数学引擎对齐） |

## 2. 探索窗口与坩埚

### 2.1 多时段坩埚（实现）

| 窗口标识 | 目标时长 | 适应度权重 |
|---------|---------|---------|
| 10y / all | 全量（最早至最新 bar） | 0.40 |
| 5y | 1825 天 | 0.30 |
| 2y | 730 天 | 0.20 |
| 6m | 183 天 | 0.10 |

- 更短窗口对齐最新 bar，并预留最多 1200 天 warmup。
- **严禁未来数据泄露**：评估区间从 EvalStartMs 开始，warmup 必须在此之前。
- 主进化回路中**不在每个体、每窗口末执行蒙特卡洛**（默认关闭），避免高成本重复模拟。

### 2.2 蒙特卡洛终审（仅 Epoch 结束）

交易序列的蒙特卡洛模拟**不进入**适应度打分。仅在 Epoch 结束时，对最终挑战者追加一次 1 分钟 K 线全样本复核回测，计算路径稳定性（Ruin Probability、分位收益等），写入档案。若指标超告警阈值，仅记录 Warn 日志，**不改写 fitness、不阻断 challenger 落库**。

### 2.3 基因空间语义操作

策略通过 Sample / Clamp / Validate 向引擎提供基因边界；引擎不直接读取字段名。

### 2.4 出生点冻结（Epoch 级）

`quant.SpawnPoint`（CapitalPolicy + RiskBounds）在 Epoch 启动时固定，全种群共享，不参与代内交叉变异。

## 3. 适应度函数（全悲观原则）

适应度是 GA 的“死神”。Score 完全决定存活或淘汰。

### 3.1 核心奖励
- **Alpha**：对比同期无脑定投（Ghost / Baseline DCA）的超额利润。最核心进化指标。
- **Cumulative Realized PnL**：微观引擎通过批次清算（PositionLot）实际落袋的绝对利润。

### 3.2 核心惩罚
- **交易摩擦**：每一次微观成交按 Spawn 配置的佣金、印花税等**双边交易成本**扣分（量级约 0.2%，以实现为准）。过度频繁交易（如 10 年 20000 次）会被摩擦成本直接抽干得分为负。
- **最小交易单位截断**：理论订单必须经 LotStep / LotMin 规范化；无法满足的订单强制丢弃，模拟真实阻断。
- **最大回撤**：对资金曲线下行波动进行指数级（或高权重）扣分，淘汰“死抗”运气基因。

### 3.3 多窗口汇总（与既有实现对齐）
- 单窗：Alpha = ROI_策略 − ROI_被动DCA；SliceScore 可叠加回撤惩罚项。
- Fatal：MaxDD ≥ 某硬阈值（如 88%）时 SliceScore = 灾难性极小值。
- ScoreTotal = 0.40×全量 + 0.30×5y + 0.20×2y + 0.10×6m。
- Ghost DCA 基线在 Epoch 启动时预计算；Modified Dietz 收益率剔除注资跳变。

## 4. 进化生命周期动作

### 4.1 种群初始化（1-4-5 黄金配比）
- **10% 旧神火种**：从档案库按标的/模板查询冠军/挑战者精英，原样注入；不足时回退默认染色体。Index 0 始终为当前种子冠军原样。
- **40% 伴生变异群**：在精英拷贝上施加加大尺度（约 1.5×）加性高斯扰动，覆盖整条 LunarGenome。
- **50% 外来移民**：合法参数盒内均匀随机全新个体，打破局部最优。

种群大小默认 Population = 300。

### 4.2 并发适应度评估
Workers = min(NumCPU, PopulationSize)；每个 worker 独占 Adapter，无共享可变状态。

### 4.3 选择
锥标赛 TournamentSize 默认 3。

### 4.4 交叉（优先正交块级）
在父代精英之间做**切片/块级互换**（正交组合），例如：A 的动力学感知段（kp, kv）与 B 的开火/逃顶段（ka, MinTradeThreshold）或宏观战略段组合。语义上保持“块级”正交，而非逐基因均匀打乱。具体切片边界由策略 Clamp 后修复。

（均匀交叉仍可作为 fallback 或辅助模式。）

### 4.5 变异
每基因独立 Bernoulli 概率（默认约 0.15，突变斜坡可上调至约 0.55）加性高斯扰动，投影回合法盒。

### 4.6 精英保留
Top max(1, ceil(PopSize × EliteRatio)) 个体完整克隆至下一代（EliteRatio 默认 0.05）。

### 4.7 突变斜坡
连续多代无显著改进时，优先上调突变概率与幅度（默认放大因子约 1.25），直至上限；仍无改进才 Early Stop。

### 4.8 基因组指纹缓存
FNV-1a-64（精度 1e-6），命中则跳过重复回测评估。

## 5. EvolvableStrategy 抽象接口（八动词契约）

引擎通过以下接口与具体策略完全解耦，对染色体字段名完全不可见：

| 动词 | 职责 |
|------|------|
| StrategyID() | 策略唯一标识 |
| Sample(rng) | 合法空间随机采样 |
| Mutate(c, prob, scale, rng) | 加性高斯变异 |
| Crossover(p1, p2, rng) | 交叉（块级或均匀） |
| Fingerprint(c) | 基因唯一哈希 |
| Evaluate(ctx, c, plan) | 坩埚评估，返回适应度与窗口明细 |
| DecodeElite(json) | 从 ParamPack 解码精英；null 时返回默认种子 |
| EncodeResult(c, spawn) | 序列化为 ParamPack JSON |
| Verify(...) | 全量复核回测（含可选 Monte Carlo） |

`Gene = any`：引擎持有不透明载体。

### EvaluablePlan（只读上下文）
Epoch 启动时构建，世代内不可变：Symbol / TemplateName / Spawn / LotStep·LotMin / Windows[] / DCABaselines[] / AggregateCache。

## 6. 结果交付与基因角色三态

- **challenger**：进化产出，等待人工审批。
- **champion**：当前活跃冠军。
- **retired**：历史存档。

晋升：DB 事务内 旧 champion → retired，目标 challenger → champion；Redis 冠军缓存立即失效。

实盘实例只加载当前冠军参数包；无冠军时回落产品内置默认包。

---

## 7. 回测状态机关键约定（与实盘同构）

1. **时钟对齐**：宏观 Tick（如每小时）与微观 Tick（如每分钟 / 5 分钟）在同一时间轴交替推进。
2. **库存桥（Inventory Bridge）**：宏观定投买入的 DeadHold 必须等待微观引擎侦测到加速度（ka 相关）飙升时，才可解封为 FloatHold。回测必须精准记录底仓与浮动仓之间的账本转移，与实盘 DeadStack / FloatStack 语义一致。
3. 理论订单必须经 LotStep / LotMin 截断；摩擦成本在适应度中全悲观计入。

## 8. HTTP 触发契约（最小集合）

仅在 `app_role: lab` 或 `dev` 下可用。

- **创建任务**：`pop_size`（默认 300）、`max_generations`（默认 25）、`spawn_mode`（inherit | random_once | manual）、可选 `test_mode`、可选 Environment / Season 覆盖。
- **查询**：任务状态、历次 challenger 基因列表（含 ScoreTotal、MaxDrawdown、各窗口分数、Ruin 等终审指标）。
